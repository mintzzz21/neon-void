# NEON VOID

A twin-stick neon arena survival shooter, built for the make.fun best-game-01 bounty.

Fly with **WASD / arrow keys**, aim with the **mouse**, hold **click / Space** to fire.
Survive escalating waves of chasers, weavers, splitters and shooters; chain kills for
combo multipliers; grab weapon, shield and ship drops; a boss warps in every 5th wave.
Three ships. **P** pauses, **M** mutes. Best score is kept in the browser.

Pure static files — no library, no network request, no build step. Open `game/index.html`
through any static server (or `node serve.ts`, then http://localhost:8080) and play.

Screenshots are staged renders of the real game (`?shot=start|play|boss|over&seed=7`).
